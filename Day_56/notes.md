# Top 5 Assumptions of Linear Regression

Linear Regression works properly when some important assumptions are satisfied. These assumptions help ensure that the model gives reliable and meaningful results.

### 1. Linearity

There should be a **linear relationship** between the independent variables and the dependent variable.

### 2. Independence of Observations

Each observation should be **independent** of the others. One data point should not influence another data point.

### 3. Homoscedasticity

The variance of the errors (residuals) should remain **constant** across all levels of the predicted values.

### 4. Normality of Residuals

The residuals (errors) should be **approximately normally distributed**, especially when performing statistical tests and calculating confidence intervals.

### 5. No Multicollinearity

The independent variables should not be **highly correlated with each other**. High correlation makes it difficult for the model to determine the individual effect of each feature.

## Summary

The five main assumptions are:

1. **Linearity**
2. **Independence**
3. **Homoscedasticity**
4. **Normality of Residuals**
5. **No Multicollinearity**

If these assumptions are reasonably satisfied, the Linear Regression model is more likely to produce reliable results.
